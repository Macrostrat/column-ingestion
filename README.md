# Macrostrat column ingestion format

These templates and format specification for stratigraphic column data allow preparation of stratigraphic information
for ingestion into Macrostrat using tabular formats (e.g., Excel spreadsheets).

> [!tip] New to the format?
> **Start with the [quickstart guide](./Docs/Quickstart.md)** and the
> [simple template](https://github.com/Macrostrat/column-ingestion/raw/main/Excel%20Templates/column-ingestion-template-simple.xlsx).
> The guide walks through a measured column step by step. When your data need more fields, use the
> [expanded template](https://github.com/Macrostrat/column-ingestion/raw/main/Excel%20Templates/column-ingestion-template-expanded.xlsx).

> [!caution]
> This is a draft document describing ongoing work. The format described here
> is subject to change as the specification is implemented.
